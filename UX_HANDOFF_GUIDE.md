# 📦 LogiLedger — UX Design Handoff & UI Specification Blueprint
**Target Audience:** UX AI Engineers & Product Designers  
**Core Product Mission:** Multi-tenant offline-first retail inventory portal with real-time barcode telemetry, enterprise logistics drawers, and live AI diagnostics.

---

## 🛠️ Tech Stack & Seamless Compatibility Requirements

To ensure that components generated by the **UX AI Agent** can be dropped into the **LogiLedger** repository instantly **without compiling errors or broken imports**, you must strictly adhere to the following stack specifications:

### 1. Core Framework & Language
* **React 18+ & Vite Sandbox:** Build components as modern functional React components using hooks.
* **TypeScript & Absolute Type Safety:** Do not use `any`. Specify typed interfaces for props, layout components, and data state arrays. All `import` statements must reside at the top level of the file.

### 2. Styling System (Tailwind CSS V4)
* **Direct Utility Classes:** Do not write external or module-level `.css` custom stylesheets. Use Tailwind CSS utility classes directly.
* **Colors & Theme Variable Styling:** Use modern inline palette combinations or native Tailwind colors (e.g. `indigo-600`, `slate-50`, `emerald-500/10`).

### 3. Animation Engine (`motion/react`)
* ⚠️ **CRITICAL IMPORT RULE:** **Do NOT** import from `framer-motion`. 
* **Correct Import Pattern:** Always use `motion` and `AnimatePresence` imported natively from **`motion/react`**:
  ```tsx
  import { motion, AnimatePresence } from 'motion/react';
  ```

### 4. Icon Library (`lucide-react`)
* ⚠️ **CRITICAL ICON RULE:** All SVG-based UI icons **MUST** be imported directly from the `lucide-react` library.
* **Forbidden Pattern:** Do not bundle raw `<svg>` elements or construct homemade SVG React classes in your design files.
  ```tsx
  import { Sparkles, Trash2, Layers, RefreshCw } from 'lucide-react';
  ```

### 5. Client & Server Persistence Boundaries
* **State Management:** Hold ephemeral view states within standard React hooks (`useState`, `useMemo`, `useRef`). 
* **Backend Isolation:** Security coordinates (like Firebase Config or Gemini API Keys) are guarded exclusively on our backend `server.ts` layer. Do not write front-end client-side logic that accesses `process.env` directly for API services. All telemetry calls route securely through local endpoints (e.g., `/api/cocopilot`).

## 🎨 1. Visual Identity & Stylistic System

LogiLedger uses a high-density, professional Swiss-minimalist aesthetic tailored for high-intensity, industrial, and retail operators. 
* **The "Eye-Longevity" Light Theme (Default):** Soft off-whites and cool-grays canvas paired with elevated white cards.
* **The "Telemetry Slate" Dark Accent:** Deep navy-slate blocks reserved for live physical status indicators and hardware simulator regions.

### 🎨 Color Tokens & Tailwind Mappings
* **Primary Canvas background:** `bg-[#F8FAFC]` (Slate 50) — Keeps the background crisp but soft.
* **Elevated Panels (Cards, Lists, Modals):** `bg-white border border-slate-200/80 shadow-sm`
* **Brand Accents:** 
  * *Indigo Royal:* `bg-indigo-600 text-white font-semibold hover:bg-indigo-700` — Used for main call-to-actions, bulk adjustment action states, and primary submissions.
  * *Emerald Green:* `bg-emerald-500/10 text-emerald-700 border-emerald-500/20` — Used for online indicators, synced ledger queues, and stock levels that are in-range.
  * *Rose/Red:* `bg-rose-500/10 text-rose-700 border-rose-500/20` — Used for stock-out alerts, audit discrepancies, and destructive delete confirmations.
* **Display Typography (Headings):** Pairing clean sans-serif *Inter* (`font-sans tracking-tight shrink-0 font-bold`) for structural components and *Space Grotesk* for headlines.
* **Data Indicators (High-Density Metrics):** Technical monospace *JetBrains Mono* (`font-mono text-xs uppercase text-slate-500 tracking-wider`) for SKU keys, lot numbers, audit records, and shelf labels.

## 🏛️ 2. Screen Architecture & Core Layout

The system is configured as a highly integrated, single-page application dashboard structured around **four primary visual panels**:

### A. The Global Control & Multi-Tenant Rail (Header)
* **Tenancy Selector:** Toggle dropdown allows effortless swapping between retail environments (e.g., Apex Retail, Summit Apparel). This triggers layout updates and switches isolated database contexts instantly.
* **Cloud Sync Ledger Ribbon:** An interactive indicator that senses connection states (`Online` / `Offline`). It lists outstanding local transactions waiting to sync and triggers a prompt `Manual Cloud Sync` command.

### B. High-Density Inventory Ledger Grid (Central Stage)
* **Interactive Filtering System:** A segmented-button shelf to group products by standard categories or filter views by Stock Thresholds (`All Stock`, `Low Stock`, `In Stock`, `Out of Stock`).
* **Multi-Select Bulk Adjustments Hub (Brand New!):**
  * Displays a responsive, staggered panel once one or more products are checked.
  * **Controls Included:** Bulk assign Category, instant bulk-edit Location tags, specify Vendor Supplier names, and perform dynamic math adjustments on quantities (`Exact Set`, `Addition Offset`, `Subtraction Offset`).
  * Includes a **Bulk Purge Trigger** to drop selected files cleanly from index records after rendering a safe confirmation modal.
  * *UX Expectation:* Smooth animate-in/out visual transition via `framer-motion` (AnimatePresence) when selections swap from zero to active.

### C. Enterprise Logistics Workspace (Drawer Modules)
Operators manage specialized supply chain workflows using tabs or modals:
1. **Procurement Portal (3-Way PO Match):** Supports drafting Purchase Orders for depleted inventory. Integrates a three-way comparative match comparing *Ordered Units*, *Receipt Log Metrics*, and *Final Invoiced Bills*.
2. **Expiry Cycle Counting Panel:** Provides localized warehouse counting session forms requiring serial key logs, physical counts, expiration records, and bin location labels.
3. **Fulfillment Terminal:** An interactive picking workflow with shipping routing simulations and mock live tracking progress bars.
4. **SSO Directory Management:** Displays Okta/SAML synced directory logs mapping user permissions, roles, and approval authorization limits.

### D. Server-Side AI Diagnostics Side-Dock (The Copilot Hub)
* **LLM Engine Routing Switcher:** Button blocks allow users to switch between three Gemini model backends dynamically:
  1. `gemini-3.1-flash-lite` (⚡ Lite/Low cost logs analysis)
  2. `gemini-3.5-flash` (⚖️ Balanced default analyst)
  3. `gemini-3.1-pro-preview` (🎓 Deep corporate logical calculations)
* **Interactive Text Field:** Operates a server-secured chat route passing real-time inventory metrics securely without exposing client API keys.

## ✨ 3. Signature UX Transition Guidelines
To guide the AI UX agent in making the interface feel premium and organic:
1. **Adaptive Device Frames:** The UI should fluidly adapt its layout from desktop warehouse consoles to handheld barcoding devices.
2. **Interactive Checkbox Highlight:** Table rows dynamically light up in a subtle `bg-indigo-50/30` tint when checked to ensure strong visibility over bulk arrays.
3. **No Decorative AI Slop:** Keep interface feedback grounded in standard, precise operational concepts. Do not generate fake continuous terminal log readouts (`CONNECTING...`, `SYSTEM_OK`) in background margins. Only surface functional, actionable interactive logs.
